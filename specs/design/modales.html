Modales de Viditor

Propuesta de rediseño para los diálogos: cabecera con distintivo de color, ícono, título con subtítulo opcional y la X integrada. El cuerpo y el pie quedan separados en bandas para que las acciones se encuentren siempre en el mismo lugar.

Qué cambia

Cabecera propiaBanda con fondo de cabecera de panel, igual que los paneles de la app.
Distintivo por tonoLínea superior de 2 px y ícono con fondo tintado: azul, rojo o ámbar según la acción.
X en el títuloAlineada al centro de la cabecera, con área de clic de 26 px y foco visible.
Pie fijoLas acciones van en una banda inferior, con atajos de teclado a la izquierda.

Implementación

<script setup lang="ts">
import { onMounted, onUnmounted } from 'vue'
import Icon from './Icon.vue'

type Tone = 'accent' | 'danger' | 'warn' | 'ok'

const props = withDefaults(defineProps<{
  title: string
  subtitle?: string
  icon?: string          // nombre de Icon.vue
  tone?: Tone
  width?: number
  closable?: boolean
  hint?: string          // "Esc cancelar", etc.
}>(), { tone: 'accent', width: 440, closable: true })

const emit = defineEmits<{ close: [] }>()
function onKey(e: KeyboardEvent): void { if (e.key === 'Escape') emit('close') }
onMounted(() => window.addEventListener('keydown', onKey))
onUnmounted(() => window.removeEventListener('keydown', onKey))
</script>

<template>
  <div class="backdrop" @pointerdown.self="emit('close')">
    <div class="dialog" :class="`tone-${tone}`" :style="{ width: width + 'px' }"
         role="dialog" aria-modal="true" :aria-label="title">
      <header class="head">
        <span v-if="icon" class="badge"><Icon :name="icon" :size="15" /></span>
        <div class="titles">
          <h2>{{ title }}</h2>
          <p v-if="subtitle">{{ subtitle }}</p>
        </div>
        <button v-if="closable" class="x" title="Cerrar" aria-label="Cerrar"
                data-testid="modal-close" @click="emit('close')">
          <Icon name="x" :size="14" />
        </button>
      </header>
      <div class="body"><slot /></div>
      <footer v-if="$slots.footer" class="foot">
        <span v-if="hint" class="hint">{{ hint }}</span>
        <slot name="footer" />
      </footer>
    </div>
  </div>
</template>
