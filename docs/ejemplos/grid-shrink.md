# Cuadrícula que se encoge



- **Categoría:** Geométricas
- **Duración por defecto:** 1 s
- **Audio:** crossfade
- **Referencia:** `builtin:grid-shrink`

## Parámetros

| Parámetro | Tipo | Valor por defecto |
|-----------|------|-------------------|
| Columnas (`cols`) | `int` | `4` |
| Filas (`rows`) | `int` | `3` |
| Escalonado (`stagger`) | `number` | `0.5` |
