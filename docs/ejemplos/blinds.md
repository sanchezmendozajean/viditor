# Persianas

El clip saliente se corta en franjas que se cierran una tras otra, descubriendo al entrante.

- **Categoría:** Geométricas
- **Duración por defecto:** 1 s
- **Audio:** crossfade
- **Referencia:** `builtin:blinds`

## Parámetros

| Parámetro | Tipo | Valor por defecto |
|-----------|------|-------------------|
| Franjas (`strips`) | `int` | `8` |
| Orientación (`direction`) | `enum` | `"horizontal"` |
| Escalonado (`stagger`) | `number` | `0.4` |
